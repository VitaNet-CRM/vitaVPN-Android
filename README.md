# vitaVPN

### سریع، امن، بدون محدودیت  
### Fast. Secure. Without Limits.

**vitaVPN** یک کلاینت VPN مدرن برای Android است که با تمرکز بر اتصال پایدار، رابط کاربری ساده و تجربه مناسب کاربران ایرانی طراحی شده است.

این Repository، مرجع رسمی انتشار و دانلود نسخه‌های Android برنامه **vitaVPN** است.

> سورس اصلی برنامه در این Repository منتشر نمی‌شود.  
> فایل‌های رسمی APK از طریق بخش **GitHub Releases** منتشر می‌شوند.

# vitaVPN

**Fast. Secure. Without Limits.**

vitaVPN is a modern Android VPN client designed for secure, reliable, and simple connectivity.

This repository is the official public distribution channel for **vitaVPN Android releases**.

> The application source code is not published in this repository.  
> Official APK packages are distributed through GitHub Releases.

---

## Download

Official vitaVPN APK files are published in the **Releases** section of this repository.

For most modern Android phones, including Samsung Galaxy devices, use:

**`arm64-v8a`**

A direct download link to the latest release will be added after the first public release is published.

---

## Features

- Secure VPN connectivity
- WireGuard support
- Xray-based connectivity
- Automatic connection management
- Cross-protocol failover
- Real-time connection status
- Live download and upload statistics
- Live latency measurement
- Data usage information
- Subscription validity information
- Registered device information
- Dark and Light themes
- English and Persian language support
- RTL and LTR interface support
- Responsive interface for different Android screen sizes

---

## Android Support

vitaVPN is designed for modern Android phones and different screen sizes.

Release packages may include builds for:

- `arm64-v8a`
- `armeabi-v7a`
- `x86`
- `x86_64`

### Which APK should I install?

| Device | Recommended APK |
|---|---|
| Most modern Android phones | `arm64-v8a` |
| Older 32-bit Android phones | `armeabi-v7a` |
| x86 Android devices | `x86` |
| x86_64 Android emulators/devices | `x86_64` |

If you are unsure, **arm64-v8a** is the correct choice for most current Android phones.

## Installation

1. Open the latest version from the **Releases** section.
2. Download the APK that matches your device.
3. Open the downloaded APK.
4. If Android asks for permission, allow installation from that source.
5. Install or update vitaVPN.
6. Open the application.

When updating an existing installation, you normally do **not** need to uninstall the previous version.
